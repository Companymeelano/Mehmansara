# راهنمای نصب و ساخت — MEHRA (اندروید)

## ۱. دربارهٔ نسخهٔ ۱.۴.۳

از نسخهٔ **۱.۴.۳** برنامه کاملاً **محلی (آفلاین)** است:

- **صفحهٔ ورود (نام کاربری/رمز) و اتصال به سرور به‌کلی حذف شده‌اند.**
- بلافاصله پس از نصب، برنامه مستقیم باز می‌شود و وارد صفحهٔ اصلی می‌شوید؛ تمام آیتم‌ها (اتاق‌ها، مهمان‌ها، رزروها، پذیرش، صندوق، گزارش‌ها) را **دستی** وارد می‌کنید.
- داده‌ها **روی خود دستگاه** نگهداری می‌شوند (حافظهٔ RAM — با بستن کامل برنامه پاک می‌شوند؛ نسخهٔ دائمی روی دیتابیس دستگاه در نسخهٔ بعدی).
- Nothing is pre-filled: no sample rooms/guests/reservations.

## 2. پیش‌نیازها

| ابزار | نسخه |
|---|---|
| JDK | 17 (Temurin/Microsoft/OpenJDK) — `JAVA_HOME` تنظیم شود |
| Android Studio | Ladybug (2024.2) یا جدیدتر |
| Android SDK Platform | 35 |
| Build-Tools | 35.0.0 |
| Gradle | از طریق wrapper — نیازی به نصب جداگانه نیست |
| دستگاه/امولاتور | Android 7.0 (API 24) یا بالاتر |

`local.properties` در ریشه پروژه (دستی): `sdk.dir=/path/to/Android/Sdk`

## 3. ساخت

```bash
./gradlew :app:assembleDebug     # دیباگ
./gradlew :app:assembleRelease   # ریلیز — همیشه امضاشده (v1+v2+v3)
# خروجی: app/build/outputs/apk/debug/app-debug.apk
#        app/build/outputs/apk/release/app-release.apk
```

نسخهٔ ریلیز **همیشه امضا می‌شود**: اگر `keystore.properties` موجود باشد از کلید ریلیز، وگرنه از کلید دیباگ — APK بدون امضا توسط Android اصلاً نصب نمی‌شود.

## 4. نصب روی دستگاه

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

- **قبل از نصب نسخهٔ جدید، نسخهٔ قبلی را Uninstall کنید** (کلید امضای CI هر بار ephemeral است و امضا فرق می‌کند).
- روی Xiaomi/HyperOS: اجازهٔ «نصب از apps ناشناخته» را به اپ.File Manager (مدیر فایل) بدهید.
- **بررسی اندازهٔ دقیق فایل:** اندازهٔ فایل دانلودی باید دقیقاً با عدد درج‌شده در یادداشت انتشار (release) برابر باشد؛ هر اختلافی یعنی انتقال ناقص — فایل را با Google Drive/USB منتقل کنید، نه پیام‌رسان.

## 5. اولین اجرا

1. اپ را باز کنید — **بدون هیچ صفحهٔ ورود** مستقیم وارد داشبورد می‌شوید.
2. از منوی اصلی: اتاق تعریف کنید، مهمان اضافه کنید (نام، کد ملی، تلفن، **پلاک خودرو**، شهر، نشانی)، رزرو ثبت کنید، پذیرش/تسویه انجام دهید.
3. در «تنظیمات» می‌توانید پوسته، واحد پول، قفل صفحه (PIN) و قفل خودکار را تنظیم کنید.

## 6. تنظیمات مهم نسخه

- `applicationId` = `ir.ahvaz.mehra` (دیباگ: `ir.ahvaz.mehra.debug`)
- `versionName` = `1.5.0`، `versionCode` = 11
- `allowBackup=false` — دادهٔ مهمان در بکاپ ابری قرار نمی‌گیرد.

## 7. عیب‌یابی

| نشانه | علت محتمل | راه‌حل |
|---|---|---|
| «نصب نمی‌شود / problem parsing» | APK بدون امضا یا damaged | نسخهٔ امضاشدهٔ ریلیز را نصب کنید؛ اندازهٔ فایل را با SHA256SUMS چک کنید |
| داده‌ها بعد از بستن اپ پاک شدند | فقط در نسخه‌های قبل از ۱.۴.۳ | از نسخهٔ ۱.۴.۳ به بعد داده به‌صورت رمزنگاری‌شده روی دستگاه ذخیره می‌شود و با بستن اپ پاک نمی‌شود |
| پلاک خودرو ثبت نمی‌شود | طول پلاک خارج از بازهٔ ۶ تا ۱۲ کاراکتر | مثال صحیح: `۱۲ب۳۴۵-۶۷` |
