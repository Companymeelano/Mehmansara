# DEMO.md — منسوخ از نسخهٔ ۱.۴.۰

از نسخهٔ **۱.۴.۰** «نسخهٔ نمایشی (demo flavour)» حذف شد؛ خودِ برنامه کاملاً محلی است و با نصب مستقیم باز می‌شود
(بدون سرور و بدون صفحهٔ ورود؛ همهٔ داده‌ها دستی وارد می‌شوند و خالی شروع می‌شود).

برای ساخت: `./gradlew :app:assembleRelease` — خروجی: `app/build/outputs/apk/release/app-release.apk`
راهنمای کامل: `docs/INSTALL.md` — لینک‌های دانلود: `artifacts/README.md` و انتشار GitHub `v1.3.0-android`.
