مهرآ — نسخٔ ویندوز (Mehra.exe)
سامانهٔ مدیریت مهمان‌پذیر فرهنگان اهواز — نسخٔ ۱.۱.۲

1. فایل Mehra.exe را اجرا کنید (win-x64، self-contained — نیازی به نصب .NET نیست).
2. «ورود نمایشی»: بدون سرور — با دادهٔ نمونه کامل.
3. «ورود با SQL Server»: اتصال مستقیم به Microsoft SQL Server — با نصب‌گر MehraSetup.exe، SQL Server LocalDB 2016 (سبک‌تر، ~۴۵ مگابایت) به‌صورت خودکار همراه برنامه نصب و پایگاه دادهٔ «Mehra» ساخته می‌شود (پیش‌فرض: (localdb)\MSSQLLocalDB)؛ یا به هر SQL Server موجود (2008 به بالا) متصل شوید — جداول به‌صورت خودکار ساخته می‌شوند.
4. «ورود با API»: نشانی سرور + نام کاربری/رمز عبور.
